## 2024-05-24 - Cross-Site Scripting (XSS) in Model Pickers
**Vulnerability:** Multiple React components (e.g. `ClineModelPicker.tsx`, `OpenRouterModelPicker.tsx`, `GroqModelPicker.tsx`, etc.) used `dangerouslySetInnerHTML={{ __html: item.html }}` to render highlighted search results for model IDs. The `html` string contained untrusted model names (e.g., from an API or user input) mixed with `fuse.js` highlighting syntax, without any HTML sanitization.
**Learning:** Even though `highlight()` function correctly applied `span` tags for search results, it included the original input verbatim. A malicious model ID returned from an external provider (like OpenRouter) could include arbitrary HTML/JS and cause XSS when rendered in the VSCode webview. Also, biome linting ignores were used incorrectly assuming `highlight()` sanitized the markup.
**Prevention:** Always wrap variables passed to `dangerouslySetInnerHTML` with `DOMPurify.sanitize(html)` to ensure any injected malicious script tags are removed, regardless of whether you think the data source is safe.
